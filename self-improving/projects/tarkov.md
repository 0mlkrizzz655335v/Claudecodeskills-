## CPU 核心优化详解（2026-06-05 新建）

### 核心问题
i7-12700H = 6P核(12线程) + 8E核(8线程)。Windows 调度器会把游戏线程分配到 E核 → 周期性卡顿。Tarkov Unity 引擎不识别异构 CPU。

### 解决方案：5阶段优化脚本

| 阶段 | 操作 | 技术细节 |
|------|------|----------|
| 1. 电源优化 | Turbo方案 + P核禁止停车 + Boost阈值调优 | CPMINCORES=100, 异构策略=0(默认) |
| 2. 内存清理 | 备用内存释放 + GC强制回收 | EmptyWorkingSet + GC.Collect |
| 3. 启动器 | 自动检测并启动 BsgLauncher.exe | 支持 F:/C: 双路径 |
| 4. 进程绑定 | P核亲和性(0x0FFF) + High优先级 | 500ms轮询检测，5分钟超时 |
| 5. 持续监控 | 每5秒检查亲和性/优先级是否被重置 | 游戏退出后自动关闭 |

### CPU 亲和性掩码

| 掩码 | 核心 | 用途 |
|------|------|------|
| `0x0FFF` | P核全部(0-11, 12线程) | **默认** — 游戏用6P核超线程，最大化P核吞吐 |
| `0x0555` | P核物理(0,2,4,6,8,10) | 备选 — 仅6物理核，更好的缓存利用率 |
| `0xFF000` | E核全部(12-19, 8线程) | ❌ 绝不使用 — 性能灾难 |

### 使用方法

```
右键 F:\EFT\启动塔科夫.bat → 以管理员身份运行

```

## 关键优化项
- CPU: **P核绑定(0x0FFF) + High优先级 + 禁止停车 + 持久线程** ← 本轮重点
- 电源: Turbo方案 + Boost阈值优化
- GPU: DLSS Quality + Reflex On+Boost + SSR/SSAO关闭
- 内存: 16GB + 自动清备用内存 + AutoEmptyWorkingSet
- 网络: TCP优化 + Nagle关闭 + NIC省电关闭
- Defender: 排除EFT路径和进程
