# Codex 写作 Skills 包 · 导入说明

## 这是什么

你 PC 上已有的 8 个"自然写作"系列 skill，打包成 Codex 可直接用的格式。
**不需要新建 `zh-writing-polish`**——`qu-ai-wei`（中文深改）+ `humanizer-zh-academic`
（论文润色）已经覆盖了中文去 AI 味，而且规则写得比新建一个更细（保真、
证据边界、语义清单都是现成的）。

8 个 skill 分工：

| skill | 干什么 |
|---|---|
| natural-writing | 总控：一般文章起草/润色，负责路由 |
| qu-ai-wei | 中文深改、整篇重组（保真） |
| humanizer-zh-academic | 中文论文语言润色 |
| research-paper-writing | 论文结构、论证、证据规划 |
| precise-prose | 技术/工作报告润色 |
| natural-fiction | 小说创作、润色、续写 |
| prose-audit | 只审稿不改写 |
| voice-profile | 提炼/匹配你的文风 |

## 导入步骤（在你电脑上）

```bash
# 1. 解压本包后，把 skills/ 下的 8 个目录复制到 Codex skills 目录
cp -r skills/* ~/.codex/skills/

# 2. （可选）在常写东西的项目里放一份 AGENTS.md
cp AGENTS.md /你的项目/.codex/AGENTS.md
```

## 验证

在 Codex 里问："列出可用的写作 skills"，
或直接下任务："用 natural-writing 润色这段文字：……"。

## 说明

- 8 个 skill 总共不到 300KB，不占上下文（按需加载 references/）。
- `prose-audit` 自带本地扫描脚本 `scripts/prose_scan.py`，只在你本机跑，
  不联网、不上传文字。
- 原包里的 system/agent/plugins 类 skill 与写作无关，没打包进来；
  需要时从你原来那份 Skills.zip 里取。
