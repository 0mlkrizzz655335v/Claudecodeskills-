# 保真边界案例

以下为原创语义压力检查，用于判断改稿是否越过原文证据；不能仅靠数字扫描脚本完成。

| 原稿 | 改稿 | 结论 |
|---|---|---|
| 尚不能把延期归因于人手不足 | 延期与人手数量无关 | 改变证据状态，扩大排除范围 |
| A 并非唯一原因 | A 不是原因 | 删除了 A 仍可能是原因的含义 |
| 培训后评分较高[2]。作者推测练习也可能影响评分 | 培训和练习均提高评分[2] | 把先后改因果、推测改确定，引用支持范围被扩大 |
| 两组结果与假设相符 | 两组结果出乎作者预料 | 改变研究者预期，无来源增加反应 |
| 仿真显示本工况下有改善 | 实机验证各工况均有效 | 改变证据类型和外推范围 |
| A 为 481 ms，B 为 342 ms | 两者相差 142 ms | 新增计算错误；差值应为 139 ms |

新计算只能由输入材料推出，计算正确仍不等于允许补“远超预期”“具有实际意义”。原始数据本身矛盾时先标注，不能改数据配合结论。

检查论文时，把“编辑可以修正”的语言问题和“必须补文献、数据或研究设计”的问题分开。若证据未补齐，不能因为句子更顺就标为已解决。
