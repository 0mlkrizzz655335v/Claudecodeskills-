# 中文学术编辑

| 常见问题 | 适用处理 | 必须保护 |
|---|---|---|
| 每段都以理论名起笔 | 有原文支持的现象时，可调整信息顺序 | 理论归属；不能为调整位置虚构观察 |
| 每段都“此案例印证了” | 删除纯重复，或直接说明真正新增的发现 | 新发现、适用范围及证据强度 |
| 并列理由等长等重 | 按材料中的重要性和内容量安排详略 | 真实独立理由；不为了破三项删一项 |
| “该方法体现了……”空泛 | 材料有设计理由时写清理由 | 未提供研究过程时不编失败尝试或访谈 |
| “核心问题是……”不断开场 | 直接提出具体问题 | 不擅自换研究对象、地区、样本和任务 |
| 高频抽象词堆叠 | 用准确动词或已给事实表达 | 专业术语和有实质意义的程度差异 |
| “研究表明”缺引文 | 提示补来源，或在授权下核验 | 不能改成作者观点来掩盖来源缺口 |
| 结尾泛化价值 | 留下正文已经支持的结论与限制 | 不新增一个未经分析的可检验命题来凑结尾 |

“一个句子只留一个限定词”不能作为通则。“部分样本在高温条件下可能发生……”同时包含范围、条件与不确定性，三者都有意义。

## 原创示例：重组而不创造观察

原文：“本研究依据故障树方法整理了 16 条既有故障记录。该处理体现了结构化分析的价值。其中 4 条记录缺少温度信息，因此相关分支尚未完成验证。”

改稿：“本研究用故障树方法整理了 16 条既有故障记录。其中 4 条缺少温度信息，相关分支尚未完成验证。”

删去的是无新信息的价值评价。不能改成“现场试验确认了故障根因”，也不能写成“4 条记录由温度异常引起”。

## 原创示例：保留真实理论表述

原文：“根据能量守恒关系，输入能量等于系统储能变化与输出能量之和。”

如果任务只是降低 AI 味，这句话可以保留。理论名称处于句首并不构成问题；不为位置指标改成某次未发生的实验叙述。

## 原创示例：作者反应不可伪造

原文：“两组结果与研究假设相符，但长期效果尚不明确。”

可保留，或写：“两组结果符合研究假设，长期效果仍不明确。”

不能加入“研究者惊讶地发现”“远超预期”，不能去掉“长期”把不确定性扩大到全部结果。
