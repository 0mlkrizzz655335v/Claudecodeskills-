# 文风卡

按实际材料选择字段，不为了完整填写未知内容。没有足够依据的项写“样本不足”，而不是猜测。

| 字段 | 记录方法 |
|---|---|
| 适用范围 | 哪类文本和哪些读者；不能把私人日记口吻推广到正式报告 |
| 样本依据 | 样文标识、相关位置、是否用户明示；不要求附全文 |
| 叙述距离 | 第一人称、面向读者、客观说明；根据用法判断，不推断身份 |
| 信息顺序 | 实际如何开场、给例子、表达保留意见和结束 |
| 句段节奏 | 哪些信息写长、哪里停顿；避免转成固定字数 |
| 词汇层次 | 常用书面或口语表达，必须保留的术语，不宜强加的口头禅 |
| 判断方式 | 结论先行或推理展开，怎样表达不同意见及不确定性 |
| 情绪与幽默 | 有依据时记录幽默类型及使用场景；别凭一个感叹号归纳性格 |
| 标点与版式 | 一致的标点、列表或段落习惯；保留目标格式要求 |
| 稳定特征与例外 | 区分跨样文反复出现、仅本篇出现及场景变化 |
| 应用边界 | 不迁移样文中的事实、身份、观点、私人经历和独特成句 |

## 原创示例

样文 A：“这本书我读得很慢。倒不是难，是每看几页就想翻回去：前面那个例子，好像还有另一种解释。”

样文 B：“我先把结论放这儿：够用。缺点也有，目录不好找，第一次翻的时候我找了半天。”

可提炼：先给简短判断，再补具体的保留意见；使用平常词语；允许口语转折。依据仅有两段，不能推断作者总是短句或总是幽默。

目标材料：“这份手册足够入门使用，列出了常用术语；但目录没有页码。”

可改：“入门用，够了。常用术语都列在里面，就是目录没有页码，查起来不方便。”

注意：这里“查起来不方便”是对目录缺页码的普通评价，不是虚构使用经历。不能改成“我翻了半小时才找到”，也不能复制样文关于书中例子的内容。

## 应用检查

把稿件同样文放在一起，看说话距离、信息次序和判断方式是否接近。仅仅重复“说实话”“我觉得”不算保留声音。若不符，修正一两个最影响声音的选择，避免全篇套上一种过浓的口吻。
