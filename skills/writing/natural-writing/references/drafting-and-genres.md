# 起草与体裁

## 从主题形成正文

先找文章要回答的具体问题及读者为什么会关心，再把可用材料分为已知事实、作者判断和明确假设。不要把这个内部过程机械输出成提纲。

有素材就以素材决定写什么。只有主题时，可以做合适的解释和推理；需使用时效事实、精确数据或外部例证时，按任务及环境要求检索并核实。没有核实的内容不能装成采访或亲历。用户限定仅用所给材料时，不能擅自扩展证据范围。

为问题安排足够的证据、例子和解释，略过读者已经知道的背景。各段可以不同长，不为了“全面”增加互不相关的角度。标题应与正文实际兑现的内容相符。

起草后从读者角度复读：哪个问题尚未回答，哪段只是变着说法重复，哪个结论比材料更强。根据真实缺口修改；不要给成稿一层统一的聊天口吻。

## 体裁选择

| 体裁 | 内容应完成什么 | 容易误用的去味动作 |
|---|---|---|
| 公众号、博客、评论 | 形成清晰问题、证据和作者判断；对有分歧处给理由 | 伪造“我有个朋友”的开头，段段强行金句，没依据地选边 |
| 科普、教程 | 先解答读者实际困惑，再提供所需解释、步骤和适用范围 | 删掉关键步骤或准确术语，假定所有人都是初学者 |
| 产品与项目介绍 | 写明给谁用、能做什么、当前完成状态及实际限制 | 用“秒级”“领先”“用户喜爱”等无来源承诺替换抽象卖点 |
| 短帖、社交文案 | 传达一个足够明确的观察或信息，适配读者和平台 | 假装熟人聊天、塞热词、硬加互动问题和标签 |
| 口播、演讲 | 让人听一次能跟上；保留必要重复、停顿和口头衔接 | 为避免重复剪掉听觉路标，照搬书面长句或每句都断行 |
| 个人随笔、读后感 | 用真实观察、理解和感受组织内容 | 代写不属于作者的经历或臆造书中情节；一律升华人生 |
| 邮件、工作消息 | 使对方知道情况、要求、依据及必要时间点 | 删正常礼貌称谓，增加用户未承诺的期限与交付 |
| 长篇非虚构 | 控制主线、证据覆盖、术语和章节关系 | 每章重复导语和总结，删减到材料失去层次 |

这些是内容判断，不是固定篇章模版。目标格式明确时照做；平台字数限制、投稿规则等不清楚时，不凭记忆断言当前要求。

## 取材与观点

观点文章允许鲜明立场；写清它依赖的事实和判断，保留真实分歧。评论不能以虚构体验冒充证据。读后感可以写“我理解为”，前提是承接材料，不假称读过没有拿到的章节。

没有事实细节可用时，解释一个已知关系通常比编造小故事更合适。需要假设例子时，用“假设”“例如，设想”明确框定，不把假设后半段转成真实调查结果。

篇幅不足时补证据、推理或可用示例；材料只支持短文时写短。用户要求长文而材料不足以支撑事实性细节，应说明缺口或采用透明的分析性展开，不能用更多空话填字数。
