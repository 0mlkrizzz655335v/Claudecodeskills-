# 中文编辑模式

下面是编辑线索，不是禁词表。只有表达空泛、成串重复、逻辑不明或与体裁冲突时才修改。先读前后文，再决定保留、删减、重组或补问材料。

## 内容与判断

| 线索 | 需要判断什么 | 编辑动作 |
|---|---|---|
| “在当今快速发展的时代” | 是否提供理解主题所必需的具体背景 | 直接进入材料中的问题；若时代背景重要，写明已知变化。 |
| “具有重要意义”“开启新篇章” | 重要性有无实际依据 | 保留可支持的影响，删装饰性拔高；不另编成效。 |
| “赋能”“闭环”“多维度”成串 | 是有定义的业务概念，还是代替了解释 | 术语必要则解释对象和机制；空泛包装则改成普通动词。 |
| “专家指出”“研究显示” | 原文或材料是否给出可追溯出处 | 用已有来源及范围；缺出处则标待核实，不造机构和年份。 |
| “这充分证明了” | 证据是否只支持一种可能解释 | 保留原有不确定性；改变实质判断时说明。 |
| “毫无疑问”“所有人都” | 是否省略了关键例外 | 按材料收窄，不能为了有观点扩大结论。 |
| “真相藏在……” | 去掉悬念语气后还剩什么信息 | 写清实际区别；无区别便删。 |
| “从效率到温度” | 两端是否构成可解释的范围 | 分别说明真实涉及的内容，不用跨度代替关系。 |

## 句法与用词

| 线索 | 需要判断什么 | 编辑动作 |
|---|---|---|
| “对于……而言，在……方面”反复 | 话题是否可以直接作主语 | 把原有对象放前面，减少层层框架。 |
| “进行一个……的实现” | 是否存在多余的动作名词 | 用原来的核心动词表达。 |
| “基于……从而使得……得以……” | 条件、因果、结果的指向是否清楚 | 按真实关系拆开，不随意删除条件。 |
| 长串“的” | 修饰语到底修饰什么 | 分出独立信息，保留限定对象。 |
| “这”“它”“相关方面”连续 | 读者能否定位具体所指 | 恢复材料已有的名词，不凭空补主体。 |
| “不仅……更……”“不是……而是……”连用 | 对比是否承担新的论证 | 有效对比保留；装饰性反转改成直接陈述。 |
| “首先、其次、此外、最后”机械轮换 | 本来是否有顺序或递进 | 真有步骤则保留；否则用实际句段关系推进。 |
| 三项抽象形容词一组 | 是否每项都有独立含义 | 按信息数量取舍，真实三项不删；不硬凑两项或四项。 |
| “主人公／主角／中心人物”轮换 | 是否其实指同一对象 | 稳定用词，用句法解决重复。 |
| “极其、非常、无比”堆积 | 强调来自内容还是副词 | 保留必要程度差异，删重复强调，不禁用所有副词。 |
| 句句短促、断句如口号 | 关系是否被切断 | 合并属于同一判断的句子，恢复原因和条件。 |
| 每句都相近长度 | 是否让重点失去轻重 | 按信息负担调整，不随机加长缩短。 |

## 篇章与声音

| 线索 | 需要判断什么 | 编辑动作 |
|---|---|---|
| 每节都“定义—三点—意义” | 各节本来是否需要同样安排 | 让例子、论证、比较各用合适结构；保留必要模板。 |
| 标题后第一句复述标题 | 是否补充了有用信息 | 删复述，直接进入实质内容。 |
| 一段一个强行金句 | 读者是否反复被迫停下来 | 让重要判断得到展开，其余结尾自然停下。 |
| 自问自答成串 | 问题是否真代表读者疑惑 | 保留解释难点的问答；删用来宣布答案的铺垫。 |
| “有人可能会反驳” | 是否真有相关反对意见 | 有依据就回应；凭空设靶则删。 |
| 每段都提醒“值得注意” | 重点是否来自提示语而非内容 | 直接讲值得注意的内容，不换成另一种提示。 |
| 正反各占一半 | 两面的证据是否同等 | 按证据和文章任务分配篇幅，不为显得客观硬平衡。 |
| “我当时”“说实话”突然出现 | 是否来自作者材料与稳定语气 | 保留真实声音，去掉虚构亲历和装熟。 |
| 末段突然上升到时代和人生 | 是否回答开头的问题 | 回到本篇结论、可知限制或具体后续；不另起宏大话题。 |
| 助手开场和服务式收尾 | 是正文还是交付包装 | 正文清除；真实邮件称谓及礼貌结尾保留。 |

## 中文标点和格式

中文正文沿用一致的中文标点；简体稿通常用“……”和《……》，已有「……」体系时可沿用。不要把中文引号当成 AI 痕迹改为英文直引号。

保留技术字符串、代码、公式、链接目标、引文原貌和规范术语。中英混排遵循用户或项目约定，避免为了统一空格改坏标识符。中文破折号“——”可用于真实的插说或中断，检查密集使用而非一刀切。

有顺序的操作、对照项目、检查清单可用列表或表格。段落更合适时再去掉机械的小标题、粗体标签和装饰表情；平台明确需要相应风格时适应平台。

## 原创编辑示例

以下原文均为本技能编写的演示材料，修改稿只使用对应原文中已有的事实。

**套话及信息保留**

原文：本次更新具有重要意义，不仅赋能业务，更为效率提升注入新动力。更新新增批量导出，原来需要逐条导出；离线编辑仍不支持。

改写：这次更新新增了批量导出，用户不用再逐条导出。离线编辑仍不支持。

**中文句法**

原文：对于首次借阅的读者而言，在办理手续方面，需要进行一个借书卡的申请，之后方可进行图书借阅。

改写：首次借阅的读者需要先申请借书卡，再借书。

**保留限定**

原文：在本次 18 人试用中，11 人表示新界面更容易使用，这可能说明布局调整有所帮助；尚不能判断长期使用效果。

改写：本次试用共 18 人，其中 11 人觉得新界面更好用。布局调整可能有所帮助，但长期使用效果还无法判断。

**缺材料就不补数**

原文：本次调整简化了审批流程。

可保留：本次调整简化了审批流程。

只有用户要求具体成效时，才询问省去了哪些步骤、有无耗时记录。不能自行写成“审批从 5 天缩短到 2 天”。

**真实对比应保留**

原文：这不是退款，而是把款项转成账户余额。

保留：对比区分了两种实质不同的处理方式，删除前半句会损失信息。
