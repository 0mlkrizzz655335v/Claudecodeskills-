# 语义边界

## 改写前后的对应项

对齐主体、动作、对象、时间、范围、完成状态、条件、否定、数值单位、来源和结论。数字相同不代表含义相同；两个对象之间的数值、原因和引用也可能被调换。

| 原文含义 | 应保留的界限 | 不可擅自推成 |
|---|---|---|
| 尚不能把延期归因于人手不足 | 当前证据不足以确认该归因 | 延期与人手数量无关；人手充足 |
| A 并非唯一原因 | 可能还有别的原因 | A 不是原因 |
| 未发现裂纹 | 在既定检查范围中没有发现 | 没有裂纹；已排除所有缺陷 |
| 部分样本可能受影响 | 样本范围和不确定性 | 样本均受影响 |
| 仅当 X 且 Y 成立 | 两项同时成立才满足条件 | X 或 Y 成立即可 |
| 计划在月底完成 | 预期或计划 | 已完成；保证月底交付 |
| 结果与假设相符 | 观察与原假设的对应 | 结果出乎作者预料 |

不要用“不能归因于努力不足”推出“与努力程度无关”或“大家一直很努力”。前者排除了更多因果可能，后者新增正面事实和时间范围。

## 引用绑定

原创素材：“培训后评分较高[2]。作者推测，练习次数也可能影响评分。”

可改：“培训后评分较高[2]。练习次数是否也影响评分，作者认为仍有可能。”

不可改：“培训提高评分，练习次数也影响评分[2]。”这既增加因果与确定性，又让引用覆盖原本仅属作者推测的主张。更稳妥的改法通常保留原来的两句话。

直接引语默认原样保留。引号外的声称不能悄悄写进引文，来源缺失不能补一个看似真实的作者或年份。

## 评价与解决办法

原文只有“需要完善协作机制”时，不改成“指定负责人、设置三天期限、增加每周例会”。这些是新建议。可以把表达写顺，或在用户授权提出方案后另列建议。

无依据的装饰性赞词可删；实质评价、不同意见或案例不能因为不够漂亮而删除。分清修辞强度和证据强度。

## 数值

保留原值、精度和单位。新增差值或比例只有任务需要且计算可核实时才写，注明计算含义。原稿存在运算冲突时标出，不静默替换原始测量值。

如材料给出 481 ms 和 342 ms，差值为 139 ms；这项计算本身不支持“远超预期”或“具有实践意义”。
