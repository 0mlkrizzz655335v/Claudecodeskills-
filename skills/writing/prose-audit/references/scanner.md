# 只读审稿辅助

脚本用 Python 3 标准库读取本地 UTF-8 纯文本或 Markdown，向标准输出写 JSON。没有网络调用、文件改写、自动修复或第三方依赖。Word/PDF 需先按相应文件工作流提取可审阅文本；不要直接把二进制文件传入。

在当前技能实际目录中运行，或将脚本路径替换为当前目录下的绝对路径；技能文件夹可能更名，不要固定写死安装目录。

```bash
python3 scripts/prose_scan.py '/path/to/article.md'
python3 scripts/prose_scan.py --compare '/path/to/before.md' '/path/to/after.md'
```

默认模式返回观察词和句式的行列位置、原文片段及检查提示，还可定位字面重复段落。短文无需强行运行。

数字比较返回前后阿拉伯数字的词面、上下文和出现次数变化。它不能判断语义等价：即便数字集合相同，交换数值对应的人物、单位变化、删否定词都可能严重失真。中文数字、公式语义、引用归属也需人工检查。

两种模式都跳过开头 YAML 元数据、常见 Markdown 围栏代码、简单行内代码和 URL。默认文风扫描另跳过 Markdown 引用行、中文成对引号及简单英文双引号；数字比较保留引用中的数字。跨行复杂嵌套引号、复杂 Markdown、缩进代码、HTML 和不完整标记不保证正确识别；需要回看原文，不能宣称解析完整。

退出码 0 只表示读取和报告完成，不能当作文章通过审稿。输入或参数错误返回 2。脚本没有生成概率、自然度总分或检测器通过率字段。

脚本提示“研究显示”时，先看相邻引文；提示“不是……而是……”时，先看区别是否实质成立。程序没有替代这两步判断。
